# TailCatch / 마인크래프트 꼬리잡기

- ```/꼬리잡기 월드보더 <크기>``` 입력 시 게임 시작 시 월드보더 설정
- ```/꼬리잡기 시작``` 타겟 랜덤 설정 및 설정한 월드보더 내 랜덤 스폰
- ```/꼬리잡기 종료``` 게임 종료
- ```/닉네임 <이름> <색깔>``` 커스텀 닉네임 설정 가능

- 다이아몬드 우클릭 시 타겟 위치 추적 가능
